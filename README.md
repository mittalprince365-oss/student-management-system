# Student Management System

A PHP + MySQL CRUD web application for managing student records.

## Features
- Add student
- Update student
- Delete student
- Duplicate email validation
- Responsive frontend UI

## Tech Stack
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Setup
1. Clone repo
2. Import sms.sql into phpMyAdmin
3. Configure db.php
4. Run on localhost
